# 私人作品书架

面向个人使用的网页书架，在 Windows 电脑直接运行，通过局域网供手机访问。数据存储在本机 SQLite 数据库。

## 开发范围

1. 复用 Yamtrack 的作品、评分和观看记录模型，提供中文书架入口。
2. 接入 Bangumi，区分小说、漫画、动画、剧集与游戏；电影使用 TMDB 中文资料，小说以 QQ 阅读公开目录补充。
3. 支持名称和资料站链接检索、批量候选多选、自定义作品及观看链接保存。每部作品分别记录状态、星级评分与感想。
4. 使用 Steam 应用 ID 保存游戏库、商店链接和封面；有游玩时长默认进行中，同步时更新时长和可用封面，保留个人评分、感想、手动状态和链接。
5. 清单保存在 SQLite 中，支持分页自动保存、统一导入和复用名单。可粘贴纯名称或「类型 | 名称 | 记录」混合清单。
6. 搜索框下提供按类型的个性化推荐与热门候选，最多 50 部、每页 12 部，选择后进入导入确认。
7. 自定义收藏文件夹支持创建、改名、删除；同一作品可加入多个文件夹，分类与类型、状态、名称筛选共同生效。
8. 保存草稿、导入与修改个人记录后返回进入前的页面，保留筛选及推荐页码。

## 推荐排序

候选来自 Bangumi 社区热度、QQ 阅读公开榜单与作者目录、TMDB 热门及相关作品。当前用户的收藏按评分优先选择偏好样本；未评分作品的状态与封顶后的游戏时长提供较弱信号。个人评分和感想保留在本机，仅请求公开作品资料。

作者、标签与简介转换为 TF-IDF 稀疏向量，按余弦相似度计算偏好匹配。高评分形成正向权重，低评分降低相似作品的排名，再结合各来源归一化热度和经过平滑的社区评分。最终逐项选取时对过于相似的候选施加惩罚，兼顾题材多样性。已识别的同名作品和相同来源 ID 去重。

算法思路参考 [Recommenders 的 TF-IDF 内容推荐](https://github.com/recommenders-team/recommenders/blob/main/recommenders/models/tfidf/tfidf_utils.py)、[LightFM 的内容特征与反馈结合](https://github.com/lyst/lightfm)及 [MMR 多样性选择](https://github.com/langchain-ai/langchain/blob/master/libs/core/langchain_core/vectorstores/utils.py)。本项目使用 Python 标准库实现排序，不需要训练服务。它利用当前用户的偏好与公开元数据，不依赖跨用户行为数据集。

公开资料在本进程缓存一小时，个人排序每次读取当前书架，评分修改立即参与计算。推荐通过独立请求加载；单个资料源失败时展示可用结果，全部不可用时可重试或继续搜索。加入清单使用绑定当前用户的限时签名，并沿用导入确认流程。

## 部署

使用 Python、Waitress 与 SQLite。Web 服务和后台同步运行在一个本机进程中，定时任务沿用数据库中的调度记录。访问端口为 8000。

密钥放在项目根目录 `.env`，数据库及本机运行文件位于 `src/db/`。启动与停止分别使用根目录的 `start.ps1` 和 `stop.ps1`。

## 验收

- 手机和电脑访问同一书架，未登录不能读取个人记录。
- 类型、状态均支持多选并与名称组合筛选，勾选即更新；分页、刷新与浏览器前进后退保留条件。
- 中文名称和受支持链接能检索作品，小说与漫画分开选择。
- 批量结果经确认后保存，重复提交不重复建立个人条目。
- 搜索失败仍能按名称创建作品，评分和状态均允许留空。
- Steam 重复同步更新时长，个人评分和状态保持稳定。
- 草稿翻页、刷新和恢复后保留每部作品的选择、评分与记录。
- 从任意一页导入所有已选作品；已有书架记录保持原样。
- 打分时空状态默认已完成，明确选择的其他状态及手动留空优先。
- 推荐随评分调整，排除已有收藏；不同账户的偏好和推荐导入相互隔离。
- 推荐类型、热门切换及失败重试正常，不阻塞名称搜索。
- 推荐分页、刷新及浏览器前进后退保留类型、模式和页码。
- 草稿保存、导入和个人记录保存返回进入前的页面，拒绝外站跳转地址。
- 同一作品可归入多个文件夹；删除文件夹保留作品，不同账户的文件夹相互隔离。
- 本机服务重启后，书架和同步计划仍然存在。
