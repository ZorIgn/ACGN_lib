# 私人作品书架

面向个人使用的网页书架，在 Windows 电脑直接运行，通过局域网供手机访问。数据存储在本机 SQLite 数据库。

## 开发范围

1. 复用 Yamtrack 的作品、评分和观看记录模型，提供中文书架入口。
2. 接入 Bangumi，区分小说、漫画、动画、剧集与游戏；电影使用 TMDB 中文资料，小说以 QQ 阅读公开目录补充。
3. 支持名称和资料站链接检索、批量候选多选、自定义作品及观看链接保存。每部作品分别记录状态、星级评分与感想。
4. 使用 Steam 应用 ID 保存游戏库、商店链接和封面；有游玩时长默认进行中，同步时更新时长和可用封面，保留个人评分、感想、手动状态和链接。
5. 清单保存在 SQLite 中，支持分页自动保存、统一导入和复用名单。可粘贴纯名称或「类型 | 名称 | 记录」混合清单。

## 部署

使用 Python、Waitress 与 SQLite。Web 服务和后台同步运行在一个本机进程中，定时任务沿用数据库中的调度记录。访问端口为 8000。

密钥放在项目根目录 `.env`，数据库及本机运行文件位于 `src/db/`。启动与停止分别使用根目录的 `start.ps1` 和 `stop.ps1`。

## 验收

- 手机和电脑访问同一书架，未登录不能读取个人记录。
- 类型、状态均支持多选并与名称组合筛选，勾选即更新；分页、刷新与浏览器前进后退保留条件。
- 中文名称和受支持链接能检索作品，小说与漫画分开选择。
- 批量结果经确认后保存，重复提交不重复建立个人条目。
- 搜索失败仍能按名称创建作品，评分和状态均允许留空。
- Steam 重复同步更新时长，个人评分和状态保持稳定。
- 草稿翻页、刷新和恢复后保留每部作品的选择、评分与记录。
- 从任意一页导入所有已选作品；已有书架记录保持原样。
- 打分时空状态默认已完成，明确选择的其他状态及手动留空优先。
- 本机服务重启后，书架和同步计划仍然存在。
