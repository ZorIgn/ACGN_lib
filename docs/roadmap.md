# ACGLib 迭代路线图

ACGLib 面向个人 ACGN 收藏：作品资料自动检索，评价和记录归自己管理，电脑与同一 Wi-Fi 下的手机共用。迭代优先减少重复录入、保护已填内容，并保持 Windows 本机运行的轻量形态。

## 需求与顺序

| 顺序 | 需求 | 使用场景与验收目标 | 状态 |
| --- | --- | --- | --- |
| 1 | 阅读 / 观看位置与续读入口 | 在详情记录“第320章”或“第二季第4集”；书架显示位置，点击保存的链接继续阅读或观看。 | 已实现 |
| 2 | 书架批量整理 | 跨页、跨筛选保留多选；统一修改状态、加入或移出指定文件夹，保留评分、感想和其他分类。 | 已实现 |
| 3 | 推荐反馈 | 对不想看的作品标记“不感兴趣”；个人推荐和热门均排除，可撤销最近一次操作，并在原位置补入候选。 | 已实现 |
| 4 | 作品数据迁移 | 导出 JSON / CSV；上传 JSON 后先预览再确认，保留已有记录，恢复新作品的评分、位置、链接、时长和分类。 | 已实现 |
| 5 | 推荐与资料的持久缓存 | 应用重启后仍能先看已获取的推荐；断网时保留可浏览内容，恢复联网后更新。 | 已实现 |
| 6 | 第三方网站快捷收藏 | 用户主动触发浏览器收藏入口，将当前标题与链接带入添加页，确认作品匹配后保存。 | 已实现 |
| 7 | 系列、分卷与版本关联 | 分别评分各部、各季、各卷，并能查看它们的关联；重复合并前预览记录与分类的处理结果。 | 已实现 |
| 8 | 更多平台记录导入 | Bangumi 公开收藏预览后导入；PS 接入条件见平台说明。 | Bangumi 已实现，PS 接入评估完成 |

## 当前使用规则

- 阅读 / 观看位置是自由文本，由本人填写，适配不同第三方网站的章节和集数表达。
- 批量选择保留在当前浏览器标签页，按登录账户区分；执行成功、清空选择或退出多选后清除。
- 不感兴趣记录保存在本机账户下；当前推荐页面可撤销最近一次操作。公开目录有可用候选时，原位置会补入另一部作品。
- JSON 迁移范围为作品与个人记录、收藏文件夹、系列与版本关联；CSV 用于表格查看。完整应用备份仍需在停止应用后保存 `src/db/` 与 `.env`。
- 已获取的推荐与作品资料在本机持久保存，过期内容先展示、后台更新；联网后可重新加载。未获取过的资料和未缓存的远程封面需要联网。
- 快捷收藏由浏览器书签主动带入页面标题与链接，确认匹配后才加入作品。
- 关联组保留各部作品独立记录；合并预览列出字段取值、笔记、文件夹和关联组，记录变化后需重新预览。
- Bangumi 公开收藏包括各状态、评分与吐槽；导入范围及 PS 接入条件见[平台记录导入](platform-imports.md)。

## 产品参考

- [Yamtrack](https://github.com/FuzzyGrim/Yamtrack)：统一记录多种媒介的状态、评分、进度和笔记，并支持导入导出。ACGLib 的位置输入侧重分散网站上的手动记录。
- [Hardcover 批量编辑](https://roadmap.hardcover.app/feature-requests/posts/bulk-edit)：多选后集中整理收藏，减少逐项打开的操作。
- [Trakt 推荐隐藏接口](https://docs.trakt.tv/reference/deleterecommendationsmovieshide)：让用户直接排除不想看到的推荐。ACGLib 将反馈保存在本机。
- [Ryot 数据导出](https://docs.ryot.io/exporting.html)：以 JSON 保存可迁移数据。ACGLib 提供浏览器直接下载和上传预览。
