连接前准备
  1. 在 Steam 客户端或网页端打开“编辑个人资料 → 隐私设置”，将“个人资料”与“游戏详情”设为公开，并取消勾选“始终将我的总游戏时间保密”。
  2. 从个人账户详情中复制 17 位纯数字的 SteamID64（以 7656119 开头）。
  3. 前往 Steam 官方页面 ↗ 生成 Web API 密钥。

同步规则：已存在的游戏条目仅刷新累计游玩时长，不会覆盖你现有的评分、状态和个人记录。新条目将按游玩时长自动设定状态。
